# PC 画面の改善要望

- ステータス: **実装完了**。P-02〜P-04 と一覧のまとめて操作は [要件](requirements.md) の FR-17 に移した（正はそちら）。
  FR-9「作り込まない」の例外として、FR-17 の範囲に限って認めた。
- スマホ側は [スマホ画面設計](mobile-screens.md) が持つ。768px 未満は `AppLayout` を
  出し分ける方針なので、ここの変更はその既定路線と整合させる。

## 1. 要望

使っていて出た要望。優先度は付けていない。

| ID | 要望 | 規模 |
| --- | --- | --- |
| P-01 | 本文を画面幅いっぱいに使う | 対応済み |
| P-02 | 会話に「次へ / 前へ」を付ける | 大 |
| P-03 | 一覧と本文を分割ビューにする（既定） | 大 |
| P-04 | 本文を全画面で開くボタン。設定で既定を選べる | 中 |

### P-01 本文の幅 — 対応済み

スレッド表示だけ `max-w-[1000px] mx-auto` で中央寄せだった。一覧は元から幅の指定が
無く全幅なので、本文もそれに揃えた（`src/ui/routes/ThreadDetail.tsx`）。

### P-02 次へ / 前へ — 実装方針

一覧の順序と位置を「一覧の状態を保つ層」= `src/ui/lib/listState.ts`（モジュールストア）に持たせる。
`Inbox` が取得したスレッド ID の並びを保存し、`ThreadDetail` が `prevNext()` で前後を引く。
一覧をまだ読んでいない（直リンク・通知から開いた）ときは前へ/次へを無効にして出さない。
絞り込み（メールボックス・表示）は URL（`?view=`・`?address=`）とストアの両方で保ち、会話を閉じて
一覧に戻るとスクロール位置ごと復元する（通知から開いた会話を閉じたときも同じ）。キーボードショートカットは作らない（非目標）。

### P-03 分割ビュー

クリックしたら右に本文が出る形（Yahoo メール式）を既定にしたい。

今は `/` と `/threads/:id` が排他のルートで、`AppLayout` の単一 `<Outlet />` を
入れ替える**画面遷移型**。分割ペインの下地は無い（リサイズ可能なペインの実装も、
その手の依存も無い）。

ただし `AppLayout` は既に flex なので、2 カラム化の改造自体は素直に入る見込み。
P-02 の「一覧の状態を保つ層」があれば、そのまま流用できる。

**決定**: 左右に分ける。一覧側は幅 380px に絞って 差出人・件名・時刻を 2 行で出す。
本文が未選択なら右に「会話を選んでください」の導線を出し、URL は今の `/threads/:id` を保つ
（直リンクでも分割で開く）。

### P-04 全画面ボタンと既定の設定

P-03 を入れるなら、本文だけを広く見たい場面のために全画面の導線も要る。
設定でどちらを既定にするか選べるとなおよい。

**決定（置き場）**: `src/ui/lib/viewPrefs.ts` で localStorage に持つ（テーマ用の `theme.ts` と同じ流儀）。
本文の上部に小さな「全画面 / 分割」の切り替えを置き、分割を畳んで本文だけにする。
FR-9「設定最小限」の例外として、表示の設定は localStorage に留めサーバは増やさない。

## 3. 見る範囲（FR-4 / FR-19）— 実装済み

PC もスマホも同じ部品で出す（`AppLayout.tsx`）。

- **管理者モードの帯** `AdminModeBanner.tsx`: 管理者モード中は画面の最上部に赤い帯「管理者モード中 — 全員のメールを読めます（あと mm:ss）」と
  「終える」を常に出す。残り時間は `GET /v1/me` の `adminModeUntil` から 1 秒ごとに数え、0 になったら me を読み直して帯を消す。
- **切り替え** `AdminModeToggle.tsx`: owner だけ、上部右のアカウントメニューの先頭（「メンバーを追加」の上）に「管理者モード」。押すと確認
  （「全員のメールを読めます。1 時間で自動で切れ、入ったことは記録されます」）→ `POST /v1/me/admin-mode` → 画面を読み直す。
  モード中は同じ場所が「管理者モードを終える」になる。
- **会話** `ThreadDetail.tsx`: 管理者モードで読めるだけの会話（`ownAddressIds` に無い）は、開いても自動既読にせず、スター・︙メニュー（ゴミ箱・未読）を出さない。
- **非表示**: メールボックス切り替えの各行に「非表示にする / 表示する」。非表示の行は薄くし「非表示」のタグを付ける。
  「すべてのメールボックス」のときだけ「非表示も表示」のチェックが出る（`localStorage` に保つ。受信箱と検索の両方に効く）。
  メールボックスを名指しで選べば、非表示でもそのまま出る。
- **設定 `/settings`「外部アドレス」**: 今の外部アドレスと「確認済み / 未確認」。入力して「登録して確認メールを送る」→ 未確認なら
  6 桁の「確認コード」欄と「確認メールを送り直す」「確認する」。送れるドメインが無いときは API の `reason` をそのまま出す。
- **メンバー追加**（上部メニューの「メンバーを追加」`AddMemberDialog.tsx`、管理画面の「ユーザーを作成」`UsersPage.tsx`）:
  「プライマリアドレス」を必須にし、「新しく作る（ローカル部 @ ドメイン）」か「既存から選ぶ（アーカイブされていないメールボックス）」。
  「外部アドレス」は任意（owner を作るときだけ必須）。作成後の案内は「ログイン: <プライマリか外部アドレス>」と仮パスワード。
- **管理画面のユーザー**: 一覧と詳細に「外部メール（認証済み / 未認証）」「プライマリ」。プライマリの無い人には ⚠。
  詳細の「プライマリを変更」は write で割り当てたメールボックスから選ぶ。権限の編集でプライマリを read にすると赤字で止める。
  アドレスの「見られる人」は割り当てた人だけになり、「所有者」の行は無くなった（プライマリの人に「プライマリ」のバッジ）。
  アドレス作成に「自分（作成したオーナー）に write で割り当てる」のチェック。
